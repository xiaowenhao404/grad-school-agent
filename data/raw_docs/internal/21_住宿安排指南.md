## 一、住宿类型概述

### 1.1 主要住宿类型

| 类型 | 优点 | 缺点 | 适合人群 |
|------|------|------|---------|
| 学校宿舍 | 安全、方便、社交机会多 | 价格较高、空间有限 | 新生第一年 |
| 校外租房 | 价格灵活、空间大 | 需要自己找房、承担水电费 | 高年级学生 |
| Homestay | 语言环境好、了解当地文化 | 需适应家庭规则 | 本科生、语言学生 |
| 学生公寓 | 管理规范、设施完善 | 价格偏高 | 独立生活能力强的学生 |

## 二、学校宿舍

### 2.1 申请流程

1. **查看宿舍选项**：访问学校宿舍官网
2. **了解申请截止日期**：通常与 offer 接受截止日期相近
3. **提交宿舍申请**：通过学校系统申请
4. **支付押金**：确认宿舍后需支付押金
5. **等待分配**：学校会根据申请和到达日期分配

### 2.2 宿舍类型

| 类型 | 描述 | 价格范围 |
|------|------|---------|
| 单人间 | 独立卧室，共享客厅/厨房 | $800-1500/月 |
| 双人间 | 与室友共享卧室 | $500-1000/月 |
| Studio | 独立小公寓，含厨房 | $1200-2000/月 |
| Apartment | 多卧室公寓 | $1500-3000/月 |

### 2.3 宿舍注意事项

- **申请要趁早**：热门学校的宿舍非常抢手
- **了解合同期限**：通常为 1 年（academic year）
- **查看取消政策**：万一需要换房要提前了解
- **设施清单**：了解宿舍提供的家具和电器

## 三、校外租房

### 3.1 找房渠道

| 渠道 | 说明 |
|------|------|
| 学校推荐 | 学校官网的 housing board |
| 学长学姐 | 最可靠的渠道，了解真实情况 |
| Facebook Groups | 各校的中国学生群、租房群 |
| Craigslist | 美国常用的租房平台 |
| Rightmove/Zoopla | 英国常用租房平台 |
| 58同城/小红书 | 澳洲、香港常用 |

### 3.2 找房时间

| 地区 | 建议开始找房时间 |
|------|----------------|
| 美国 | 到达前 2-3 个月 |
| 英国 | 到达前 3-4 个月 |
| 香港 | 到达前 2-3 个月 |
| 新加坡 | 到达前 2 个月 |
| 澳洲 | 到达前 2 个月 |

### 3.3 租房注意事项

**合同相关**：
- [ ] 仔细阅读合同条款
- [ ] 了解租期（通常 12 个月）
- [ ] 了解押金数额和退还条件
- [ ] 了解提前解约条款
- [ ] 了解 bills 是否包含（水电费）

**费用相关**：
- [ ] 房租金额和支付方式
- [ ] 押金数额（通常 1-2 个月房租）
- [ ] 中介费（如有）
- [ ] 账单（电费、燃气费、网络费）

**房屋检查**：
- [ ] 入住前拍照记录房间状态
- [ ] 检查家具电器是否正常
- [ ] 测试水龙头、门锁等
- [ ] 了解物业维修流程

## 四、Homestay（寄宿家庭）

### 4.1 适合人群

- 本科学生，尤其是 18 岁以下
- 希望提高语言能力的学生
- 不想自己做饭的学生
- 初到异国希望有人照顾的学生

### 4.2 费用

- 通常包含三餐
- 费用：$800-1500/月（包食宿）
- 部分家庭不含周末餐食

### 4.3 注意事项

- **尊重家庭规则**：作息时间、洗澡时间等
- **沟通问题**：有困难要及时沟通
- **保持整洁**：自己的房间和公共区域
- **参与家庭活动**：有助于融入当地文化

## 五、各国/地区租房特点

### 5.1 美国

**特点**：
- 通常需要签署 12 个月租约
- 押金通常为 1 个月房租
- 多数不含 bills（水电费另算）
- 通常不带家具

**热门区域**：
- 学校周边步行可达区域（最贵）
- 地铁/公交沿线（价格适中）
- 郊区（价格便宜但需车）

### 5.2 英国

**特点**：
- 学生公寓很普遍，设施完善
- 私人租房通常为 6-12 个月
- Bills 包与不包价格差异大
- 部分房屋有 HMO 许可

**热门区域**：
- 学校步行 20 分钟内（最贵）
- 地铁/公交沿线
- 共享房屋（House share）

### 5.3 香港

**特点**：
- 房租昂贵，空间狭小
- 通常为整套出租，需合租分摊
- 实用面积 vs 建筑面积差异大
- 多数不带家具

**热门区域**：
- 学校周边（沙田、港大、西营盘等）
- 地铁沿线（价格递减）
- 深圳关口附近（价格便宜但通勤长）

### 5.4 新加坡

**特点**：
- 政府组屋（HDB）租金相对便宜
- 公寓（Condo）设施更好但贵
- 通常包 bills
- 押金为 1-2 个月

### 5.5 澳洲

**特点**：
- 学生公寓选择多
- 私人租房通常 6-12 个月
- 部分含家具
- 押金为 4 周房租
