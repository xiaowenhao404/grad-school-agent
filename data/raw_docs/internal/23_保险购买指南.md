## 一、保险概述

留学海外，保险是必不可少的保障。不同国家和地区对保险有不同的要求，选择合适的保险既能满足要求又能节省开支。

### 1.1 为什么需要保险

- **签证要求**：多数国家强制要求
- **医疗保障**：海外医疗费用高昂
- **意外保障**：留学期间的意外风险
- **财产保障**：行李丢失、手机被盗等

### 1.2 保险类型

| 类型 | 覆盖范围 | 必要性 |
|------|---------|--------|
| 健康保险 | 医疗费用 | 强制要求 |
| 意外险 | 意外身故/伤残 | 建议购买 |
| 旅行险 | 航班延误、行李丢失 | 建议购买 |
| 财产险 | 贵重物品 | 可选 |

## 二、各国保险要求

### 2.1 美国

**强制要求**：
- F-1 学生必须购买符合要求的健康保险
- 通常通过学校购买或自行购买满足学校要求的保险
- J-1 访问学者同样要求

**学校保险 vs 自行购买**：
| 对比项 | 学校保险 | 自行购买 |
|--------|---------|---------|
| 价格 | 通常较贵 ($1500-3000/年) | 可更便宜 |
| 便利性 | 直接绑定，省心 | 需自行管理 |
| 覆盖 | 通常较好 | 需仔细挑选 |
| 豁免 | 符合条件可申请 | 需满足要求 |

### 2.2 英国

**强制要求**：
- NHS（National Health Service）医疗免费
- 签证申请时需缴纳 IHS（Immigration Health Surcharge）
- IHS 费用：£776/年

**建议购买**：
- 私人医疗保险（补充 NHS）
- 牙科保险（可选）
- 旅行险（往返中国时）

### 2.3 澳洲

**强制要求**：
- 必须购买 OSHC（Overseas Student Health Cover）
- 可通过学校购买或自行购买

**OSHC 提供商**：
- Allianz Global Assistance
- BUPA Australia
- Medibank
- NIB
- AHM

### 2.4 加拿大

**强制要求**：
- 部分省份强制要求健康保险
- 国际学生通常需购买省级健康保险或私人保险

**各省情况**：
| 省份 | 要求 | 说明 |
|------|------|------|
| 安大略 | 强制 | UHIP（大学健康保险计划） |
| BC 省 | 强制 | MSP（医疗服务计划） |
| 其他省 | 建议 | 购买私人保险 |

### 2.5 香港/新加坡

- 不强制要求健康保险
- 建议购买覆盖全球的旅行险或健康险
- 公立医院费用相对较低

## 三、健康保险选择指南

### 3.1 选择要点

| 要点 | 说明 |
|------|------|
| 覆盖范围 | 看是否包含门诊、住院、处方药 |
| 报销比例 | 越高越好 |
| 最高赔付 | 是否有上限 |
| 免赔额 | 越低越好 |
| 网络医院 | 是否包含你学校的医院 |
| 紧急救援 | 是否有 24 小时紧急救援 |
| 既往症 | 是否覆盖已有疾病 |

### 3.2 必选覆盖

- 门诊（Outpatient）
- 住院（Inpatient）
- 紧急救护（Emergency）
- 处方药（Prescription Drugs）
- 体检（Preventive Care）

### 3.3 推荐覆盖

- 牙科（Dental）
- 眼科（Vision）
- 心理健康（Mental Health）
- 孕产（Pregnancy）
- 既往症（Pre-existing Conditions）

## 四、意外险

### 4.1 为什么需要

- 健康保险通常不覆盖意外身故/伤残
- 留学期间户外活动较多
- 保费便宜，保障高

### 4.2 选择要点

- 身故/伤残保额（建议 50-100 万）
- 意外医疗（通常 1-5 万）
- 紧急救援
- 覆盖地区（确保包含留学目的地）

---

## 五、旅行险

### 5.1 什么时候需要

- 往返中国期间
- 假期出游时
- 短期交换项目

### 5.2 覆盖内容

| 覆盖 | 说明 |
|------|------|
| 航班延误 | 延误超过一定时间赔付 |
| 行李丢失 | 赔付丢失行李 |
| 行程取消 | 因故取消行程赔付 |
| 紧急救援 | 境外紧急医疗转运 |
| 个人责任 | 造成第三方损失的赔偿 |

## 六、推荐保险方案

### 6.1 美国留学生

**方案一：学校保险**
- 优点：省心、覆盖好
- 缺点：价格较高
- 适合：新生第一年

**方案二：校外保险**
- 推荐：Student Medicover、International Student Insurance
- 优点：价格灵活
- 缺点：需自行管理
- 适合：高年级学生

### 6.2 英国留学生

**基础方案**：
- IHS（已包含在签证费中）
- 私人旅行险（往返时购买）

**增强方案**：
- IHS + 私人补充医疗险
- 牙科保险（如有需要）

### 6.3 澳洲留学生

**必选**：
- OSHC（学校或自行购买）
- 推荐：Bupa（华人服务好）

**可选**：
- 额外私人保险（牙科、视力）

### 6.4 申根地区留学生

- 申根签证要求覆盖 3 万欧元的旅行医疗保险
- 推荐：安联、AXA 等申根保险

## 七、购买渠道

### 7.1 国内渠道

| 渠道 | 特点 |
|------|------|
| 保险公司官网 | 产品多，可比较 |
| 支付宝/微信 | 方便快捷 |
| 保险经纪 | 专业建议 |
| 学校推荐 | 通常有合作优惠 |

### 7.2 国外渠道

| 渠道 | 特点 |
|------|------|
| 学校保险计划 | 方便，通常质量有保证 |
| 国际学生保险平台 | 如 ISO Insurance、International Student Insurance |
| 当地保险公司 | 当地购买，价格可能更低 |

## 八、理赔流程

### 8.1 一般流程

1. **就医**：前往网络医院或诊所
2. **付款**：先垫付或出示保险卡
3. **收集材料**：病历、收据、处方等
4. **提交理赔**：通过官网或 APP 提交
5. **等待审核**：通常 1-4 周
6. **获得赔付**：打到银行卡

### 8.2 注意事项

- 保留所有原始单据
- 了解报销流程和时限
- 紧急情况先就医再报案
- 及时报案，避免超过时限
