# 德国学生签证指南

> 无忧留学服务公司 | 签证咨询部
> 更新时间：2026年1月

---

## 一、德国签证概述

德国属于申根区。中国学生申请德国长期学习（超过 90 天）需要申请 **德国国家签证（D 类）**，通常与德国的居留许可（Aufenthaltserlaubnis）挂钩。

### 1.1 基本要求

- 被德国认可的高等教育机构录取
- 具备足够的德语或英语能力
- 证明有足够的经济来源
- 购买德国健康保险
- 参加APS审核

### 1.2 适用人群

- 申请德国公立大学（本科、硕士、博士）
- 申请德国艺术学院
- 申请德国语言班（需匹配条件）

---

## 二、APS 审核

### 2.1 什么是 APS

APS（Akademische Prüfstelle）是德国驻华使馆文化处留德人员审核部，负责审核中国学生的学历真实性。

### 2.2 审核流程

**一般国内申请人（TestAS）**：
1. 注册 APS 在线系统
2. 准备材料公证
3. 提交材料并缴费
4. 参加 TestAS（德适）考试
5. 获得 APS 证书

**硕士申请人（面谈）**：
1. 注册 APS 在线系统
2. 准备材料公证
3. 提交材料并缴费
4. 参加面谈（20 分钟左右）
5. 获得 APS 证书

### 2.3 APS 证书

- APS 证书是申请德国签证的必要材料
- 有效期：永久
- 申请硕士最多可申请 5 所学校

---

## 三、申请流程

### 3.1 获得录取

1. 申请德国大学
2. 获得录取通知书（Zulassung）
3. 接受录取，缴纳学期费（Semesterbeitrag）

### 3.2 签证申请

1. **预约面签**：在德国驻华使馆预约签证面签时间
2. **准备材料**
3. **前往使馆面签**
4. **等待审批**（通常 4-8 周）
5. **获得签证**

## 四、所需材料

### 4.1 基本材料

| 材料 | 说明 |
|------|------|
| 护照 | 有效期超过在德停留期 6 个月以上 |
| 签证申请表 | 完整填写并签名 |
| 照片 | 3 张，35x45mm，白底 |
| APS 证书 | 原件 |

### 4.2 学术材料

- 录取通知书（Zulassung）
- 最高学历证明（公证件）
- 成绩单（公证件）
- 语言成绩（DSH/TestDaF 或英语成绩）

### 4.3 财务材料

**资金证明要求**：
- 约 €11,208/年（约 €934/月）
- 可以通过以下方式之一证明：
  - 德国银行 Sperrkonto（限制账户）：存入 €11,208
  - 德国担保人的担保声明（Verpflichtungserklärung）
  - 奖学金证明（DAAD、Erasmus+ 等）

### 4.4 其他材料

- 医疗保险证明（入境后必须购买德国保险）
- 个人简历
- 学习计划（Motivation Letter）
- 住宿证明

## 五、德语要求

### 5.1 公立大学德语授课

| 语言考试 | 要求 |
|---------|------|
| DSH | 通常 DSH-2 或 DSH-3 |
| TestDaF | 通常 4x4 或以上 |
| DSD | B2 或 C1 级别 |

### 5.2 英语授课项目

- 不需要德语成绩
- 通常需要雅思 6.0-6.5 或同等水平
- 部分学校要求 GRE

---

## 六、DAAD 奖学金

### 6.1 奖学金概述

DAAD（Deutscher Akademischer Austauschdienst）是德国学术交流中心，提供多种奖学金：

- 短期研究奖学金
- 硕士/博士奖学金
- 艺术家奖学金

### 6.2 申请方式

- 通过 DAAD 官方网站申请
- 或通过学校提名

| 费用项目 | 金额 |
|---------|------|
| APS 审核费 | ¥2,000 RMB |
| Sperrkonto 存款 | €11,208 |
| 签证申请费 | €75 |
| 学期费 | €150-350/学期（各校不同） |

---

## 八、注意事项

1. **APS 审核是必须的**，不可跳过
2. ** Sperrkonto 限制账户**：资金必须先存入德国银行并冻结
3. **提前准备**：APS 审核需要较长时间
4. **德语很重要**：即使申请英语项目，会德语会增加机会
