# 行前 Checklist

> 无忧留学服务公司 | 行前服务部
> 更新时间：2026年1月

---

## 一、行前准备时间线

### 6-8 周前

- [ ] 确认最终录取学校
- [ ] 缴纳学费押金
- [ ] 申请宿舍或租房
- [ ] 预订机票
- [ ] 开始整理行李

### 4-6 周前

- [ ] 申请签证
- [ ] 预约体检
- [ ] 接种疫苗（如需要）
- [ ] 开设海外银行账户
- [ ] 购买外汇

### 2-4 周前

- [ ] 确认宿舍/租房合同
- [ ] 购买保险
- [ ] 整理重要文件
- [ ] 通知银行境外用卡
- [ ] 预订接机服务

### 1 周前

- [ ] 打印所有重要文件
- [ ] 确认行李清单
- [ ] 检查电子设备
- [ ] 准备随身行李
- [ ] 与家人告别

## 二、重要文件清单

### 2.1 必备文件

| 文件 | 数量 | 说明 |
|------|------|------|
| 护照 | 原件 + 3 份复印件 | 确保有效期超过 6 个月 |
| 签证 | 原件 + 3 份复印件 | Visa Label / 居留许可 |
| I-20 / CAS / LOA | 原件 + 3 份复印件 | 学校发放的录取文件 |
| 录取通知书 | 原件 + 3 份复印件 | 打印版 |
| 成绩单 | 原件 + 2 份复印件 | 中英文版 |
| 毕业证书/学位证 | 原件 + 3 份复印件 | 公证件更好 |
| 体检证明 | 原件 + 2 份复印件 | 移民局要求格式 |
| 疫苗接种证明 | 原件 + 2 份复印件 | 如有要求 |

### 2.2 财务文件

| 文件 | 说明 |
|------|------|
| 信用卡 | 开通境外支付功能 |
| 借记卡 | 境外取现用 |
| 外汇 | 建议带 2000-3000 现金 |
| 汇票/旅行支票 | 可选 |
| 资金证明 | 备用 |
| 学校缴费收据 | 备用 |

### 2.3 联系文件

| 文件 | 说明 |
|------|------|
| 紧急联系人列表 | 家人、学校、大使馆 |
| 宿舍/租房合同 | 打印版 |
| 接机预约确认 | 打印版 |
| 学校联系人信息 | 国际学生办公室联系方式 |
| 保险单 | 打印版 |

## 三、行李清单

### 3.1 随身行李

**重要物品**：
- [ ] 护照、签证、I-20
- [ ] 机票确认单
- [ ] 钱包（少量现金、信用卡）
- [ ] 手机及充电器
- [ ] 转换插头（目的国标准）
- [ ] 应急药品（常用药）
- [ ] 眼镜/隐形眼镜（备用）

**舒适用品**：
- [ ] 颈枕
- [ ] 眼罩
- [ ] 耳塞
- [ ] 湿巾
- [ ] 零食（防止航班延误）

### 3.2 托运行李

**衣物**（根据目的地气候）：
- [ ] 内衣、袜子（5-7 套）
- [ ] T 恤、衬衫（5-7 件）
- [ ] 裤子、裙子（3-4 条）
- [ ] 外套（1-2 件）
- [ ] 正装（1 套，面试/正式场合用）
- [ ] 睡衣
- [ ] 拖鞋
- [ ] 运动服

**洗漱用品**：
- [ ] 牙刷、牙膏
- [ ] 洗发水、护发素（旅行装）
- [ ] 护肤品（习惯用的）
- [ ] 化妆品
- [ ] 剃须刀

**学习用品**：
- [ ] 笔记本电脑及配件
- [ ] 移动硬盘/U盘
- [ ] 词典（可选）
- [ ] 专业书籍（可选）
- [ ] 文具

**电子产品**：
- [ ] 手机
- [ ] 充电器
- [ ] 充电宝（注意容量限制）
- [ ] 耳机
- [ ] 转换插头（多国通用更好）
- [ ] 插线板

**生活用品**：
- [ ] 小电饭煲（可选）
- [ ] 中国调味料（适量）
- [ ] 文具
- [ ] 指甲刀
- [ ] 针线包

### 3.3 禁止携带物品

| 类型 | 说明 |
|------|------|
| 肉类制品 | 各国都有严格限制 |
| 植物种子 | 禁止入境 |
| 大量现金 | 超过申报额度需申报 |
| 违禁药物 | 处方药需带处方 |
| 盗版物品 | 版权问题 |
