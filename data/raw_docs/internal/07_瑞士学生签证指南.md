# 瑞士学生签证指南

> 无忧留学服务公司 | 签证咨询部
> 更新时间：2026年1月

## 一、瑞士签证概述

瑞士不是欧盟成员国，使用申根签证系统（短期停留）或 national visa（长期停留）。90 天以内的学习使用申根签证，超过 90 天则需要申请瑞士 national visa（D 类）。

### 1.1 基本要求

- 被瑞士认可的教育机构录取
- 持有有效护照
- 证明有足够的资金支付学费和生活费
- 购买瑞士健康保险
- 购买返程机票

### 1.2 适用人群

- 申请瑞士公立大学（苏黎世联邦理工、洛桑联邦理工等）
- 申请瑞士私立酒店管理学院
- 申请瑞士语言学校

---

## 二、申请流程

### 2.1 短期课程（90天以内）

使用申根签证（C 类）：

1. 向瑞士驻华使领馆预约
2. 准备材料
3. 面签
4. 等待审批（通常 2-3 周）

### 2.2 长期课程（超过90天）

申请 national visa（D 类）：

1. **获得录取通知**
2. **准备申请材料**
3. **向使领馆提交申请**（必须本人前往）
4. **等待审批**（瑞士联邦移民局审批，通常 8-12 周）
5. **获签后入境**
6. **抵达后注册居留**

## 三、所需材料

### 3.1 基本材料

| 材料 | 说明 |
|------|------|
| 护照 | 有效期超过在瑞士停留期 3 个月以上 |
| 签证申请表 | 填写完整并签名 |
| 照片 | 3 张，35x45mm，白底 |
| 录取通知书 | 学校签发的正式录取通知 |
| 学历证明 | 毕业证、学位证、成绩单（公证） |
| 语言成绩 | 根据学校要求提供 |

### 3.2 财务材料

**资金要求**：
- 每月约 CHF 2,000-2,500 生活费
- 需证明有足够资金覆盖整个学习期间

**可接受的证明**：
- 银行存款证明（约 CHF 25,000-30,000）
- 奖学金证明
- 父母资助声明
- 瑞士担保人的担保函（Garantie de prise en charge）

### 3.3 其他材料

- 健康保险证明（瑞士保险公司购买）
- 返程机票预订单
- 无犯罪记录证明
- 体检证明

## 五、注意事项

1. **瑞士签证审批较慢**，建议提前 4-6 个月开始准备
2. **联邦理工申请特殊**：ETH Zurich 和 EPFL 通常通过学校协助办理
3. **健康保险必须**：必须在瑞士保险公司购买
4. **资金证明严格**：瑞士对资金证明要求较高
