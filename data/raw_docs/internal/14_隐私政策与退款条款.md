# 隐私政策

## 一、信息收集

### 1.1 我们收集的信息类型

在为您提供留学咨询服务的过程中，我们可能会收集以下类型的信息：

**个人信息**
- 身份信息：姓名、性别、出生日期、国籍、护照信息
- 联系方式：电话号码、电子邮件、邮寄地址
- 学历信息：学校名称、在读年级、成绩单、语言考试成绩
- 财务信息：用于支付服务费用的相关信息

**申请材料**
- 个人陈述、简历、推荐信等文书内容
- 各类申请表格中填写的信息
- 学校录取通知书、签证结果等

**使用信息**
- 您访问我们网站的行为数据
- 与顾问沟通的记录
- 服务使用偏好

### 1.2 信息收集方式

- 您主动提供：申请表、服务协议、沟通交流
- 自动收集：网站访问日志、Cookie 数据
- 第三方来源：学校通知、考试成绩发布平台

---

## 二、信息使用

### 2.1 使用目的

我们收集的信息仅用于以下目的：

| 使用目的 | 说明 |
|---------|------|
| 留学申请服务 | 制作申请材料、提交申请、跟进申请进度 |
| 沟通联络 | 与您沟通申请事项、发送通知 |
| 支付处理 | 处理服务费用支付和退款 |
| 服务改进 | 优化我们的服务质量和流程 |
| 法律合规 | 满足法律法规要求 |

### 2.2 信息共享

我们承诺不向以下以外的第三方共享您的个人信息：

- **申请学校**：您的申请材料将提供给目标申请学校
- **支付机构**：仅用于处理费用支付
- **政府机构**：根据法律法规要求披露
- **服务合作方**：如语言培训机构、背景提升机构（需您授权）

## 三、信息保护

### 3.1 保护措施

我们采取多种技术和管理措施保护您的信息安全：

- **数据加密**：敏感信息采用加密存储和传输
- **访问控制**：严格限制员工访问权限
- **安全审计**：定期进行安全检查和漏洞修复
- **员工培训**：对员工进行信息安全意识培训

### 3.2 信息保存期限

您的个人信息将在以下期限中保留较长的一个：
- 协议约定的服务期限
- 法律法规要求的保存期限
- 解决争议所需的保存期限

# 退款条款

## 一、退款原则

我们致力于为您提供优质服务，但理解您可能因各种原因需要申请退款。以下是我们的退款政策。

## 二、退款条件与比例

### 2.1 全额退款

以下情况可申请全额退款：

| 条件 | 说明 |
|------|------|
| 未录取退款 | 甲方未被任何一所申请院校录取（适用部分套餐） |
| 服务未开始 | 签约后7日内且甲方未提交任何材料 |
| 乙方违约 | 乙方未按协议约定提供服务 |

### 2.2 部分退款

| 退款条件 | 退款比例 |
|---------|---------|
| 服务开始前取消（签约7日后、申请材料提交前） | 已付款项的80% |
| 部分申请已完成 | 退还未申请学校对应费用的50% |
| 签证被拒（非材料问题） | 未使用服务部分费用 |

### 2.3 不予退款

以下情况不予退款：
- 甲方提供虚假材料导致申请失败
- 甲方主动放弃申请或拒绝录取通知
- 甲方中途要求更换服务项目
- 全部申请材料已成功提交

## 三、退款流程

### 3.1 申请流程

1. **提交申请**：填写退款申请表（向顾问索取）
2. **材料审核**：我们将在5个工作日内审核您的申请
3. **结果通知**：审核结果将电话和邮件通知您
4. **款项退回**：审核通过后7个工作日内退回原支付账户

### 3.2 退款时间

- 支付宝/微信支付：1-3个工作日
- 银行转账：3-7个工作日
- 分期付款：按原分期计划调整

## 四、特殊情况

### 4.1 不可抗力

如因自然灾害、疫情等不可抗力导致服务无法继续，双方协商解决。

### 4.2 学校政策变更

如目标学校突然取消项目或重大变更，我们将积极协调解决方案。
